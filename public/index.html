About TASKORA API Architecture

TASKORA demonstrates clean client-server separation using Node.js and Express.js. Instead of persisting state inside browser storage, the frontend relies exclusively on asynchronous fetch() calls to synchronize with an in-memory JavaScript array on the server.

Note on In-Memory Persistence: Because tasks are stored directly in server RAM for zero-latency operations, restarting the Node.js process resets the task array back to [].
